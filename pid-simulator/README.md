# PID温度控制仿真系统 v1.0

一个基于Web的PID温度控制仿真教学软件，支持5种控制策略，实时波形显示，用户权限管理等功能。

## 功能特性

### 1. 用户登录与权限管理
- 管理员账号：`admin` / `admin123`
- 普通用户账号：`user` / `user123`
- 管理员可添加/删除用户
- 所有用户可修改自己的密码

### 2. 控制策略（5种）
- **普通PID（无限幅）**：纯PID算法，无抗积分饱和，可观察积分饱和现象
- **单回路PID（带抗饱和）**：位置式PID，条件积分抗饱和，输出限幅[-30, 30]
- **前馈+反馈控制**：前馈补偿可测干扰
- **串级PID控制**：外环控制最终输出，内环控制中间变量
- **串级+前馈控制**：串级结构叠加前馈补偿

### 3. 被控对象模型
双惯性环节串联：
```
G(s) = 1/((T₁s+1)(T₂s+1))
```

### 4. 反馈环节
一阶低通滤波器模拟传感器：
```
H(s) = 1/(Tcs + 1), Tc = 0.1s
```

### 5. 参数配置
- **温度范围**：SV 0~30°C
- **控制输出**：自动模式由控制器计算，手动模式用户直接设定
- **PID参数**：Kp、Ti、Td 运行中可实时调整
- **被控对象参数**：T1、T2、增益

### 6. 干扰功能
- 可配置方波干扰振幅和持续时间
- 干扰作用于被控对象输出端
- 倒计时显示

### 7. 波形显示
- 实时显示5条曲线：SV（红）、PV（绿）、u（蓝）、误差（青）、干扰（紫虚线）
- 可点击图例切换显示/隐藏
- Y轴自适应缩放

### 8. 历史记录
- 自动记录所有仿真数据
- 支持按时间段查询
- 可导出为CSV文件（可用Excel打开）

## 使用方法

### 直接打开
1. 双击 `index.html` 文件，在浏览器中打开
2. 使用默认账号登录
3. 根据需要调整参数，点击"启动仿真"

### 启动本地服务器（推荐）
如果使用Chrome等浏览器，建议启动本地服务器以获得最佳体验：

```bash
# 使用Python
python -m http.server 8080

# 或使用Node.js的http-server
npx http-server -p 8080
```

然后在浏览器中访问 `http://localhost:8080`

- Edge 80+

## 技术栈
- HTML5 Canvas 绘制波形
- 原生 JavaScript（ES6+）
- LocalStorage 存储用户数据

## 注意事项
1. 用户数据存储在浏览器本地，清除浏览器数据会重置为默认账号
2. 建议使用Chrome或Edge浏览器获得最佳性能
3. 仿真数据保存在内存中，刷新页面后会丢失
